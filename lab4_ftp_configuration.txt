RHCE RH254 HANDS-ON LAB: FTP SERVER CONFIGURATION (VSFTPD)
==========================================================

LAB OBJECTIVE:
Configure vsftpd FTP server with anonymous and authenticated access, security controls

PREREQUISITES:
- RHEL 7/8 system with root access
- Network connectivity
- Understanding of file permissions and user management

LAB SCENARIO:
Configure secure FTP server with both anonymous and user-based access.
Implement security controls and logging for FTP operations.

EQUIPMENT NEEDED:
- RHEL system (server1: 192.168.1.10)
- FTP client for testing (command line or GUI)

LAB TASKS:

PART A: INSTALL AND BASIC CONFIGURATION
----------------------------------------

1. Install vsftpd:
   # yum install vsftpd -y
   # systemctl enable vsftpd

2. Backup original configuration:
   # cp /etc/vsftpd/vsftpd.conf /etc/vsftpd/vsftpd.conf.backup

3. Create FTP users:
   # FIXED: Using useradd instead of usermod to create new users
   # Using /sbin/nologin for security (FTP only, no SSH access)
   # useradd -s /sbin/nologin ftpuser1
   # useradd -s /sbin/nologin ftpuser2
   
   # Set passwords (use strong passwords in production)
   # echo "ftpuser1:password123" | chpasswd
   # echo "ftpuser2:password123" | chpasswd
   
   # Alternative: Set password interactively
   # passwd ftpuser1
   # passwd ftpuser2

4. Create FTP directories:
   # mkdir -p /var/ftp/pub/upload
   # mkdir -p /home/ftpuser1/ftp-data
   # mkdir -p /home/ftpuser2/ftp-data
   
   # FIXED: Changed permissions to 755 for ftp-data (was causing 553 error)
   # chmod 755 /var/ftp/pub
   # chmod 777 /var/ftp/pub/upload
   # chmod 755 /home/ftpuser1/ftp-data
   # chmod 755 /home/ftpuser2/ftp-data
   
   # Set correct ownership
   # chown ftpuser1:ftpuser1 /home/ftpuser1/ftp-data
   # chown ftpuser2:ftpuser2 /home/ftpuser2/ftp-data

PART B: CONFIGURE VSFTPD MAIN SETTINGS
---------------------------------------

1. Install vim editor:
   # yum install vim -y

2. Edit main configuration (/etc/vsftpd/vsftpd.conf):
   # vim /etc/vsftpd/vsftpd.conf
   
   # Basic settings
   anonymous_enable=YES
   local_enable=YES
   write_enable=YES
   local_umask=022
   
   # Anonymous user settings
   anon_upload_enable=YES
   anon_mkdir_write_enable=YES
   anon_root=/var/ftp
   # REMOVED: Duplicate anon_upload_enable=YES line
   anon_world_readable_only=NO
   allow_writeable_chroot=YES
   
   # Security settings
   chroot_local_user=YES
   chroot_list_enable=YES
   chroot_list_file=/etc/vsftpd/chroot_list
   
   # Logging
   xferlog_enable=YES
   xferlog_std_format=YES
   xferlog_file=/var/log/xferlog
   
   # Connection settings
   connect_from_port_20=YES
   listen=YES
   # FIXED: Must be NO when listen=YES (was causing OOPS error)
   listen_ipv6=NO
   
   # User restrictions
   # FIXED: Changed from NO to YES to properly enforce user list
   userlist_enable=YES
   userlist_deny=NO
   # FIXED: Correct path with underscore
   userlist_file=/etc/vsftpd/user_list
   
   # Passive mode settings
   pasv_enable=YES
   pasv_min_port=30000
   pasv_max_port=31000
   
   # ADDED: PAM service name for authentication
   pam_service_name=vsftpd

PART C: CONFIGURE USER ACCESS CONTROLS
---------------------------------------

1. Create chroot exception list:
   # echo "ftpuser1" > /etc/vsftpd/chroot_list
   # echo "ftpuser2" >> /etc/vsftpd/chroot_list
   
   # Set correct permissions
   # chmod 600 /etc/vsftpd/chroot_list

2. Create allowed users list:
   # FIXED: Correct filename with underscore (user_list not userlist)
   # echo "ftpuser1" > /etc/vsftpd/user_list
   # echo "ftpuser2" >> /etc/vsftpd/user_list
   
   # Set correct permissions
   # chmod 600 /etc/vsftpd/user_list

3. Configure PAM to allow /sbin/nologin users:
   # CRITICAL: This allows FTP access for users with /sbin/nologin shell
   # vim /etc/pam.d/vsftpd
   
   # Comment out this line:
   #auth       required     pam_shells.so
   
   # Or use sed command:
   # sed -i 's/^auth.*pam_shells.so/#&/' /etc/pam.d/vsftpd

4. Configure SELinux for FTP:
   # setsebool -P ftpd_full_access on
   # setsebool -P ftpd_anon_write on
   # setsebool -P ftpd_connect_all_unreserved on
   
   # Set SELinux context for upload directory
   # semanage fcontext -a -t public_content_rw_t "/var/ftp/pub/upload(/.*)?"
   # restorecon -R /var/ftp
   
   # ADDED: Restore context for user directories
   # restorecon -R /home/ftpuser1
   # restorecon -R /home/ftpuser2

5. Set up firewall:
   # yum install firewalld -y
   # systemctl start firewalld
   # systemctl enable firewalld
   
   # Allow FTP service and passive ports
   # firewall-cmd --permanent --add-service=ftp
   # firewall-cmd --permanent --add-port=30000-31000/tcp
   # firewall-cmd --reload
   
   # Verify firewall rules
   # firewall-cmd --list-all

PART D: ADVANCED SECURITY CONFIGURATION
----------------------------------------

1. Configure SSL/TLS encryption:
   # Create SSL directories
   # mkdir -p /etc/ssl/private
   # mkdir -p /etc/ssl/certs
   # chmod 700 /etc/ssl/private
   
   # Generate self-signed certificate
   # openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
     -keyout /etc/ssl/private/vsftpd.key \
     -out /etc/ssl/certs/vsftpd.crt \
     -subj "/C=US/ST=State/L=City/O=Company/CN=ftp.example.com"
   
   # Set correct permissions
   # chmod 600 /etc/ssl/private/vsftpd.key
   # chmod 644 /etc/ssl/certs/vsftpd.crt
   
   # Restore SELinux context
   # restorecon -Rv /etc/ssl
   
   # Add SSL settings to vsftpd.conf
   # vim /etc/vsftpd/vsftpd.conf
   
   ssl_enable=YES
   allow_anon_ssl=NO
   # NOTE: Set to NO for testing, YES for production security
   force_local_data_ssl=NO
   force_local_logins_ssl=NO
   ssl_tlsv1=YES
   ssl_sslv2=NO
   ssl_sslv3=NO
   rsa_cert_file=/etc/ssl/certs/vsftpd.crt
   rsa_private_key_file=/etc/ssl/private/vsftpd.key

2. Configure connection limits:
   # vim /etc/vsftpd/vsftpd.conf
   
   max_clients=50
   max_per_ip=3
   local_max_rate=1000000
   anon_max_rate=500000

3. Configure banner and messages:
   # vim /etc/vsftpd/vsftpd.conf
   
   ftpd_banner=Welcome to Company FTP Server
   banner_file=/etc/vsftpd/banner
   
   # Create banner file
   # echo "Authorized users only!" > /etc/vsftpd/banner

================================================================================
QUICK REFERENCE - COMMON ERRORS AND SOLUTIONS
================================================================================

ERROR: 500 OOPS: can only support ipv4 and ipv6 currently
SOLUTION: Set listen=YES and listen_ipv6=NO in vsftpd.conf

ERROR: 500 OOPS: cannot read user list file
SOLUTION: Create /etc/vsftpd/user_list with correct permissions (600)

ERROR: 530 Login incorrect
SOLUTION: 1) Create users with useradd
          2) Set userlist_enable=YES
          3) Add users to /etc/vsftpd/user_list
          4) Comment pam_shells.so in /etc/pam.d/vsftpd

ERROR: 553 Could not create file
SOLUTION: 1) chmod 755 /home/ftpuser1/ftp-data
          2) chown ftpuser1:ftpuser1 /home/ftpuser1/ftp-data
          3) setsebool -P ftpd_full_access on
          4) Use correct PUT syntax

ERROR: Connection refused
SOLUTION: 1) systemctl start vsftpd
          2) firewall-cmd --add-service=ftp
          3) Check port 21 is listening
